PointFive has incorporated FOCUS 1.0 data exports into its Analytics module. This advancement allows users to access cloud performance and cost analysis information through a standardized format across all cloud providers.

## About FOCUS

The FinOps Open Cost and Usage Specification (FOCUS) establishes requirements for cloud vendors to generate billing files in a consistent format. This initiative, supported by the FinOps Foundation, reduces complexity around data normalization and simplifies FinOps practices across multi-cloud environments.

## Analytics Module Features

PointFive offers two FOCUS-complemented dashboards: **Overview** and **Cost Analysis**.

### Overview Dashboard

The Overview dashboard delivers a unified view of your cloud costs, enabling quick analysis and deeper insights across services, providers, and resources while streamlining cost management decisions.

### Cost Analysis Dashboard

The Cost Analysis dashboard enables users to connect expenses and usage information to various cost drivers. It includes:

- **Advanced grouping capabilities** — Organize costs by any dimension
- **Cross-filtering** — Drill into specific segments of spend
- **Deep resource-level dives** — Investigate individual resource costs
- **Investigative features** — Track down the root cause of cost changes

## Cloud Provider Support

These dashboards currently work with billing and usage data from participating providers, including AWS, Azure, and Google Cloud Platform — all normalized through the FOCUS standard for consistent cross-cloud analysis.

## Getting Started

Teams using PointFive Analytics can access the FOCUS-standardized dashboards immediately. The integration requires no additional configuration — FOCUS data exports are automatically normalized and presented through the existing Analytics interface.

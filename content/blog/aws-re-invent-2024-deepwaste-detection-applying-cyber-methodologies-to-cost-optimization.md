## Lightning Talk at re:Invent 2024

At AWS re:Invent 2024, Sharon Gross and Dor Azouri from PointFive presented a lightning talk on DeepWaste detection technology. The session explored how methodologies traditionally used in cybersecurity threat detection can be repurposed for cloud cost optimization.

## The Cyber-to-Cost Connection

The core concept behind DeepWaste detection is that identifying cloud waste shares fundamental similarities with identifying security threats. Both require:

- Deep inspection of system behavior and patterns
- Detection of anomalies that deviate from expected baselines
- Contextual analysis to distinguish real issues from noise
- Rapid response mechanisms once issues are identified

The PointFive team leveraged their expertise in developing cybersecurity threat detection models to build technology that identifies architectural inefficiencies within cloud environments.

## DeepWaste Detection Technology

DeepWaste detection transforms cloud cost optimization by applying the same rigorous, pattern-based analysis used in cyber defense. Rather than surface-level cost monitoring, this approach examines the underlying architecture to uncover wasteful spending patterns and operational inefficiencies that traditional tools often miss.

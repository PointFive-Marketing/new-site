## Cloud Cost Optimization Stays a Top Priority

Cost optimization continues to be a top priority as demand for cloud services increases. Reducing expenses while extracting maximum value from cloud resources requires staying current with provider changes and new tooling.

## AWS Public IPv4 Address Fee

Beginning February 1, 2024, AWS implemented a new pricing structure for public IPv4 addresses. All public IPv4 addresses now incur a charge of $0.005 per IP per hour, regardless of whether they are actively used. This applies across all AWS services and regions, including EC2, RDS, and EKS nodes.

The motivation behind this change stems from IPv4 address scarcity and rising acquisition costs. AWS intends to encourage users to adopt IPv6 and use IPv4 resources more judiciously.

### Public IP Insights

To help organizations manage this change, AWS introduced **Public IP Insights**, a complimentary tool within the Amazon VPC IP Address Manager. This service provides visibility into IPv4 usage patterns, enabling organizations to:

- Track and examine public IP allocation
- Identify unused or underutilized public IPs
- Optimize their public IP security posture
- Plan migration strategies toward IPv6

## Amazon EKS Extended Support

Amazon EKS now offers extended support for Kubernetes versions through a preview feature. Rather than the traditional 14-month support window, Kubernetes versions receive support for up to 26 months after becoming generally available.

Key benefits include:

- **Extended security patches** throughout the support period
- **Operational flexibility** for enterprises planning upgrade timelines
- **Reduced pressure** on teams managing Kubernetes version migrations
- **Better planning horizons** for complex application dependencies

This extension is particularly valuable for organizations running mission-critical workloads where Kubernetes version upgrades require extensive testing and validation.

## Staying Ahead

Organizations must remain current with cloud cost optimization technologies and practices. By leveraging advancements like Public IP Insights and extended Kubernetes support, companies can enhance efficiency, reliability, and economy in their cloud operations.

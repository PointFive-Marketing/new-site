Detect anomalies early. Act instantly.

The Cost Anomaly Detection module allows teams to identify unexpected cloud spending spikes, understand their causes, and respond immediately with minimal false alerts.

## Out-of-the-Box & Custom Rules

The system offers preset anomaly detection rules alongside customizable options using flexible scopes, thresholds, and filters. This approach delivers relevant, high-signal alerts while reducing noise and false positives tailored to specific environments.

## Root Cause Analysis, Built-In

Each detected anomaly includes automatic root cause analysis identifying whether issues stem from usage changes, pricing adjustments, or specific resources. Users receive contextual insights without extensive data review.

## Smart, Actionable Alerts

Teams receive notifications via Slack or email with detailed context and recommended actions for rapid response before costs escalate.

The module is available to administrators and aims to prevent unexpected cost surprises while providing remediation context.

Incorporating FOCUS 1.0 within Analytics enables FinOps practitioners to maximize the business value of their cloud.

PointFive has integrated FOCUS 1.0 data exports into its Analytics module. Users can now access cloud performance and cost analysis data in a unified location leveraging consistent language across all cloud providers.

## What is FOCUS?

The FinOps Open Cost and Usage Specification (FOCUS), supported by the FinOps Foundation, defines requirements for cloud vendors to generate billing files in a single format, eliminating data normalization complexity.

## PointFive's Analytics Module: Overview and Cost Analysis Dashboards

The Overview dashboard leverages FOCUS standards for cloud billing exports, offering unified cost views and deeper insights across services, providers, and resources.

The Cost Analysis dashboard helps attribute cost and usage data to various cost drivers using advanced group-by capabilities, cross-filtering, and resource-level deep dives.

Both dashboards are available for participating cloud providers, including Google Cloud Platform (GCP).

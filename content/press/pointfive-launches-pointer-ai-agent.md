**New York, December 10, 2025** — PointFive, the pioneer of Cloud Efficiency Posture Management (CEPM), has launched Pointer — a context-aware AI agent that enables users to explore cloud cost data through natural language conversation.

## Conversational Cloud Intelligence

Pointer removes the need for individuals to rely on FinOps teams to build queries or dashboards. The agent handles both straightforward and complex questions about optimization opportunities, cost anomalies, resource configurations, and infrastructure dependencies.

Pointer can access PointFive Opportunities, Resources, Anomalies, Teams and Users, Commitment Optimizations, cost data, and Integration issues — providing a single conversational interface to the entire platform.

Sharon Gross, VP of Product at PointFive, noted that Pointer provides users a direct path to explore their infrastructure, reveal inefficiencies, and strengthen their efficiency posture — all through natural language, with the goal of removing barriers to efficient cloud operations.

## Expanding the AI Toolkit

Pointer joins a suite of AI-powered tools PointFive released throughout 2025:

- **AI Prompt Remediation** — Delivers ready-to-run, AI-generated remediation code that engineers can apply directly. It produces native Infrastructure as Code changes compatible with the agentic IDEs engineers already use.

- **Model Context Protocol (MCP) Server** — Extends cost optimization capabilities into engineering workflows through universal AI integration, allowing users to query cost data through Claude, ChatGPT, and other MCP-compatible platforms.

- **Data Explorer** — An AI-enhanced analytics engine that helps users uncover hidden optimization opportunities using natural language, with intuitive data exploration and visualizations.

## About PointFive

Cloud waste accounts for nearly 30% of total spend. PointFive helps enterprises address this challenge with Cloud Efficiency Posture Management (CEPM), proactively identifying and resolving inefficiencies. The platform continuously monitors infrastructure, identifies waste, provides actionable context, and enables one-click remediation — driving savings of 20–40%.
